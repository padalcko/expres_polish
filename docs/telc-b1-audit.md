# TELC — реконструкція за еталоном B1

8 жовтня 2026. Локальні зміни, без commit, push і публікації.

## Архітектура

Досліджено обидві мовні версії B1 і TELC, `styles/style.css`, `styles/exams.css`, обидва мовні JS-файли, форму, FAQ, чат і всі наявні зображення. B1 використовує спільні класи сайту, а не окрему систему оформлення. TELC тепер повторює цю архітектуру.

| B1 / використаний компонент | Реалізація TELC |
| --- | --- |
| `.hero`, `.hero__inner`, `.exam-hero__eyebrow` | Та сама композиція, палітра, типографіка, відступи, брендове зображення та два CTA; текст про TELC B1·B2. |
| Локальні посилання в desktop/mobile header | Структура, підготовка, контакти, FAQ. Посилання ведуть до існуючих ID. Глобальні стилі й компонування header не змінені. |
| `.cards.cards--3` у вступі | Що таке TELC: два рівні, частини іспиту, сертифікат за результатами. |
| `.cards.cards--4` для аудиторій | Школярі, резидент ЄС, навчання/робота, відмінність від державного B1. Збережені посилання на офіційні вимоги. |
| `.steps` і `.step__number` | П’ять частин іспиту з їхньою тривалістю; окремо п’ять кроків реєстрації. |
| Додаткова змістова секція в тій самій `.cards--3` | Рівні, оцінювання та сертифікати: умови B1, B2 і результат нижче B1. |
| `.cards--3` для плану підготовки | Визначення рівня, планування практики, розбір відповідей. |
| `.for-whom__layout` | Чотири картки навичок поруч із зображенням онлайн-заняття та описом формату. На desktop — дві колонки; на mobile — послідовне компонування. |

| `.location__grid`, `.location__info`, `.location__map` | Контактна картка з SVG-іконками й карта адреси школи за зразком B1; опис стосується підготовки до TELC. |

| `.section--cta`, `.cta`, `.form` | Чинна форма запису з усіма полями й інтеграціями. |
| Перелінковка після форми | Дві картки порівняння TELC та державного B1 з посиланням на відповідну мовну версію. |

Порівняно з попередньою версією окремі текстові секції про онлайн, Вроцлав, приклади завдань, визнання та оцінювання включені у відповідні візуальні блоки. Офіційні джерела зібрано після покрокової реєстрації. Зміст TELC не підмінений правилами державного B1.

## Навігація й дизайн

- Повторено фактичну реалізацію B1: sticky header, локальні якірні посилання, плавне прокручування, меню через burger, закриття мобільного меню після вибору пункту.
- B1 не має scrollspy або автоматичного активного пункту секції; TELC також не додає їх. Поточна мова позначається чинним `aria-current`.
- Використано глобальний `scroll-padding-top` (90 px / 76 px на mobile); reduced motion для TELC вимикає smooth scroll.
- Збережено контейнер 1200 px, Nunito/Inter, палітру, радіуси, тіні, шкалу відступів і breakpoints B1. Нова незалежна система CSS не створювалася.
- Додаткові правила мають `.telc-page` scope: min-width, текстові примітки, відступи повторного CTA й джерел, reduced motion.
- Головні сторінки, HTML B1, `styles/style.css`, footer та функціональність Агнешки не змінені. Зміни `.DS_Store`, що вже були в робочій копії на початку реконструкції, не належать до цієї роботи.

## Зображення

Використано два наявні ресурси проєкту:

1. `img/hero-main.png`, 1448×1086 — брендова графіка hero, та сама, що на B1.
2. `img/virtual-class.png`, 1536×1024 — наявне зображення онлайн-заняття, та саме, що в навчальному блоці B1. Воно не подається як документальна фотографія конкретного уроку чи іспиту.

Для кожного створено WebP шириною 480, 800 і 1120 px. Загалом шість файлів займають 216 122 байти. Оригінальні PNG збережені для інших сторінок. На TELC використано `srcset`, `sizes`, `width`, `height` та локалізовані alt. Hero має `fetchpriority="high"`; позаекранне зображення — `loading="lazy"` і `decoding="async"`. Зображення не повторюються в різних секціях. Для композиції B1 додаткових матеріалів не бракує.

## Контент, SEO та інтеграції

- Збережені URL, TELC title/description, canonical, UK/RU/x-default, OG/Twitter і всі JSON-LD у head.
- Один H1, послідовні H2/H3, унікальні ID. Структура компонентів UK/RU однакова.
- FAQPage відповідає видимим 14 питанням і відповідям.
- У sitemap змінено лише дати двох TELC сторінок на 2026-10-08; XML валідний.
- Форма, поля, `formType=telc_exam_lead`, `goal=exam_telc`, webhook і маршрути не змінені реконструкцією. Попередня зміна повідомлення успіху через `data-success-message` збережена; B1 має попередній fallback-текст.
- Чат Агнешки та його інтеграція збережені. TELC-запити, виправлені на попередньому етапі, залишені.
- Факти перевірені під час попереднього етапу цієї роботи: [формат TELC](https://www.telc.net/en/language-examinations/certificate-exams/polish/telc-polish-b1b2-school/), [офіційний пробний тест, друкована сторінка 39](https://www.telc.net/fileadmin/user_upload/mock_exams/Polnisch/Polnisch_B1_B2_Schule.zip), [резидент ЄС](https://www.gov.pl/web/uw-zachodniopomorski/rezydent-dlugoterminowy-ue), [визнання громадянином Польщі](https://www.gov.pl/web/dolnoslaski-uw/uznanie-za-obywatela-polskiego). Реконструкція не додає нових правил, цін, термінів або гарантій.

## Перевірки завершеної реконструкції (до наступного завдання про соціальне меню)

- TELC UK/RU: усі 8 ширин 320, 375, 390, 768, 1024, 1280, 1440, 1920 px; горизонтального переповнення й обрізаних заголовків немає.
- 64 перевірки локальних якірних переходів: заголовки залишаються нижче sticky header після завершення плавного прокручування; мобільне меню закривається.
- Порівняно B1 і TELC візуально на desktop/mobile; окремо переглянуто блок із зображенням і завантажену Google Maps.
- FAQ клавіатурою та без JavaScript, повторний CTA, меню й відкриття/закриття чату працюють.
- Форми перевірено через mock HTTP 200/500: required/email валідація, повідомлення успіху/помилки, payload, очищення після успіху й збереження даних після помилки. Реальних заявок не надсилали.
- SEO, посилання, рівність структури UK/RU, збереження form/chat/head/footer та `git diff --check` пройшли.
- Локальний Chrome без throttling: найбільший LCP 940 ms, CLS 0,03168. Це лабораторний прогін, не production CWV. Event Timing зафіксував окремі взаємодії до 320 ms; повноцінний польовий INP не вимірювався.
- Попереднє переповнення RU B1 при 320 px (342 px) відтворюється однаково з початковими та поточними CSS/JS; не є регресією TELC.
- Production, Safari/Firefox та реальна доставка в n8n не перевірялися.
