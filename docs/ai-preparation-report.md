# AI-підготовка Expres Polish — 05.11.2026

Реалізовано локально за принципом поточних `build-ai-search.py`, `build-ai-catalog.py` і `_headers` Laser Tech Service. Посилання та контент Expres Polish залишаються власними; чужі послуги, тексти або бізнесові твердження не переносилися.

## Результат

- 24 Markdown-версії всіх канонічних HTML-сторінок із sitemap: 12 UK і 12 RU. Головні сторінки мають `/index.md` і `/ru/index.md`; сторінки `.html` — однойменні `.md`.
- Повністю оновлений `llms.txt`, автоматично сформований із заголовків, описів і URL чинних сторінок.
- `llms-full.txt` містить повний витяг публічного основного контенту обох мов із посиланнями на HTML-джерела.
- `ai-catalog.json`: URL, Markdown URL, мова, заголовок, опис, мовні відповідники та SHA-256 текстового ресурсу для кожної сторінки. Це власний машиночитаний каталог, а не стандарт пошукової системи.
- Збережено старі адреси `ai/exams.md`, `ai/b1-exam.md`, `ai/telc-exam.md`; замість окремо підтримуваних англомовних переказів вони тепер містять автоматичні UK/RU витяги відповідних сторінок.
- У `<head>` кожної канонічної сторінки: `rel="alternate" type="text/markdown"` і `rel="describedby"` для llms та JSON-каталогу.
- `_headers` містить MIME-типи, `nosniff` і HTTP canonical для 24 Markdown-відповідників HTML. Це конфігурація Netlify; її застосування на production ще не перевірено.
- `robots.txt` уже дозволяє сканування і посилається на sitemap; змін не потребував. Markdown не додається в sitemap, канонічними залишаються HTML URL.

## Джерела й обмеження витягу

Джерело істини — локальні канонічні HTML зі списку `sitemap.xml`. Генератор перевіряє self-canonical, `lang`, взаємні `uk`/`ru`, `x-default`, один H1 і main, відсутність `noindex`.

Markdown зберігає заголовки, абзаци, списки, таблиці, посилання й доступний FAQ. Меню, breadcrumbs, форми, модальні вікна, чат, інтерактивні контроли та приховані елементи не потрапляють у витяг. Питання тесту, які існують тільки в JavaScript, не вигадуються та не переносяться як нібито статичний контент.

Факти, ціни й формулювання беруться з HTML без нового фактчекінгу чи редакторських змін. Зокрема, наявні відмінності формулювань рівнів A0/A1 між сторінками не уніфікувалися самовільно.

## Подальше оновлення

Після змін текстів або додавання сторінок:

```sh
python3 scripts/build-site.py
python3 scripts/build-site.py --check
python3 scripts/check-ai-search.py
python3 scripts/check-blog.py
```

Нові канонічні сторінки мають бути у sitemap; тоді генератор автоматично включить їх у всі каталоги. Згенеровані Markdown-файли вручну не редагувати. При видаленні сторінки перевірка сигналізує про її застарілий Markdown-файл, який потрібно прибрати.

Commit, push і deploy не виконано. Ця підготовка робить матеріали доступними у структурованому текстовому форматі, але не гарантує індексацію або цитування AI-системами.
